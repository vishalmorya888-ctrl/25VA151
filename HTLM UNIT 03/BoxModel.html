This is a box model example. The total width of this div is calculated as follows:
Content width (300px) + Padding (20px * 2) + Border (5px * 2) + Margin (30px * 2) = 410px total width.
This box also has a height of 150px plus padding, border, and margin.
Margin creates space outside the border, padding creates space inside the border, and the border surrounds the padding and content.
In summary,
padding, border, and margin all contribute to the overall size and spacing of the element on the page.
Note that:
width and height only define the content area.
The background-color fills the content and padding area but not the border or margin.
