CSS Selectors

CSS selectors are used to "find" (or select) the HTML elements you want to style.

CSS class selectors are used to specify a style for a group of elements. To create a class selector, you write a period (.) character, followed by the class name. You then add the style properties you want to apply to that class inside curly braces. For example, in the CSS code above, we created a class selector called "txt" that sets the text color to red, the font family to Verdana, the font size to 18 pixels, and the font weight to 600. We then applied this class to a paragraph element using the class attribute in the HTML code. As a result, the paragraph with the class "txt" is styled according to the properties defined in the CSS class selector.
