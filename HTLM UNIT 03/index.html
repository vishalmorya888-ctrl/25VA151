External CSS is a method of writing CSS code in a separate file with a .css extension. The CSS file is then linked to HTML documents using the link tag in the head section. This separation of concerns makes websites easier to maintain and update. By using external CSS, you can apply the same styles across multiple HTML pages, ensuring consistency in design and reducing redundancy. Changes made in the external CSS file will automatically reflect on all linked HTML documents, making it a powerful tool for web developers.
